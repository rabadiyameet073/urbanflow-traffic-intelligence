# Module 33: Public Page, SEO & Social Sharing Rules

> UrbanFlow is a Vite single-page app, not a content site — but the **public landing surface** (title, description, social cards, structured data, robots, sitemap) still decides how judges, voters and crawlers first see it. These rules adapt the classic technical-SEO checklist to a framework-free SPA and to the "Most Viral / Community Vote" bonus awards.

---

## 1. The Seven Rules (adapted)

| # | Rule | UrbanFlow implementation |
|---|---|---|
| 1 | **Title 50–60 characters** | Built with `fitTitle()` (helpers/meta-helpers.ts) at build time per HTML entry. Example: `UrbanFlow AI – Adaptive Traffic Signals & Emergency Preemption` (verify length with the helper). |
| 2 | **Description 120–160 characters**, unique per page | One description per HTML entry/view; written for humans; includes the value proposition and "simulation" honesty. |
| 3 | **Canonical URL set per page** (absolute, from `VITE_SITE_URL`) | Injected into each HTML entry at build time. Never a relative or placeholder canonical. Two deployments (Pages + GitHub Pages) both canonicalise to the **primary** URL. |
| 4 | **No broken internal links; empty states return 200** | Hash routes never 404; unknown hash ⇒ default view; static host serves `index.html` fallback. |
| 5 | **Image alt text** | Every content image has descriptive `alt`; decorative SVG/icons `aria-hidden="true"`. OG image has alt in `og:image:alt`. |
| 6 | **Thin-page quarantine** | Views with no standalone content (e.g. empty Pipeline view) are `noindex` if separately addressable; only the landing HTML is indexable. |
| 7 | **robots.txt, sitemap.xml, structured data** | Static `robots.txt` and `sitemap.xml` in `public/`; `SoftwareApplication` JSON-LD with `<` escaped. |

Bonus rule: **audit performance on a production build only** (`vite build && vite preview`), concurrency = 1.

## 2. Head Tags (in `index.html`, generated by the build)

```html
<title>UrbanFlow AI – Adaptive Traffic Signals & Emergency Preemption</title>
<meta name="description" content="Open-source traffic-signal simulation: adaptive control vs fixed-time on identical arrivals, safe emergency preemption and a guarded Meta AI copilot." />
<link rel="canonical" href="https://<primary-host>/" />
<meta name="viewport" content="width=device-width, initial-scale=1" />
<meta name="theme-color" content="#0B0F14" media="(prefers-color-scheme: dark)" />
<meta name="theme-color" content="#F6F8FA" media="(prefers-color-scheme: light)" />
<meta property="og:type" content="website" />
<meta property="og:title" content="UrbanFlow AI" />
<meta property="og:description" content="Adaptive traffic control with safe emergency preemption. Simulation, not real roads." />
<meta property="og:url" content="https://<primary-host>/" />
<meta property="og:image" content="https://<primary-host>/og.png" />
<meta property="og:image:alt" content="Twin view of two intersections: fixed-time versus adaptive control." />
<meta name="twitter:card" content="summary_large_image" />
```

Rules:
- Character budgets are **asserted in a test** that reads the built `dist/index.html`.
- Descriptions contain no unverifiable claims ("fastest", "best", fabricated percentages). If a result is quoted, it is generated from `results.json` at build time.
- OG image: 1200×630, < 300 KB, generated from a real screenshot (twin view) or Muse Image art — never a copyrighted photo. Prompt/provenance recorded.
- **Honest limitation:** social crawlers do not execute JS and never see the URL hash, so **share links cannot have per-run previews**; every share link previews as the generic landing card. Do not promise otherwise.

## 3. Structured Data (XSS-safe)

```ts
export function jsonLdScript(data: Record<string, unknown>): string {
  const json = JSON.stringify(data).replace(/</g, '\\u003c');       // prevents </script> breakout
  return `<script type="application/ld+json">${json}</script>`;
}
```

```json
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "UrbanFlow AI",
  "applicationCategory": "SimulationApplication",
  "operatingSystem": "Web",
  "description": "Traffic-signal simulation with adaptive control, emergency preemption and an AI copilot.",
  "offers": { "@type": "Offer", "price": "0", "priceCurrency": "USD" },
  "license": "https://opensource.org/license/mit"
}
```

Injected only at **build time** from constants (no user data). Validate with Google's Rich Results Test or schema.org validator before release.

## 4. `robots.txt` & `sitemap.xml`

```
User-agent: *
Allow: /
Disallow: /api/
Sitemap: https://<primary-host>/sitemap.xml
```

Sitemap lists the landing URL (+ any static docs pages) with `<lastmod>` set by the build. The edge API origin returns `X-Robots-Tag: noindex` on all responses.

## 5. Share-Link UX (virality without lies)

| Element | Rule |
|---|---|
| Copy link | Short toast; link includes `s=` hash state (module 31/ADR-019) |
| Footer | "state hash: ab12…" so two people can confirm identical runs |
| Social post kit | `docs/social/`: 280-char copy, 20-second GIF/MP4 from the video, hashtags per event guidance, **numbers from `results.json` only** |
| Preview card | Generic OG card (see limitation above) |
| Attribution | "Built with Muse Code / Muse Spark / SAM 3.1 / Muse Image" where accurate |

## 6. Audit Commands

```bash
# Title/description budgets from the built file
node helpers/check-meta.mjs dist/index.html

# Canonical present and absolute
grep -n 'rel="canonical"' dist/index.html

# JSON-LD escaped (should print nothing)
grep -n '</script>' dist/index.html | grep -v '^.*</script>$' || true

# Images without alt
grep -rn '<img' dist/index.html src | grep -v 'alt=' || true

# Production-build performance (concurrency = 1)
pnpm --filter @urbanflow/web build && pnpm --filter @urbanflow/web preview &
curl -o /dev/null -s -w 'Total: %{time_total}s | Status: %{http_code}\n' http://localhost:4173/
```

## 7. Pre-Release Checklist (public surface)

- [ ] Title 50–60 chars; description 120–160 chars; both unique per HTML entry.
- [ ] Canonical absolute and points to the primary URL (not localhost, not placeholder).
- [ ] OG/Twitter tags present; image loads; `og:image:alt` set.
- [ ] JSON-LD valid and escaped.
- [ ] `robots.txt`, `sitemap.xml` reachable; API origin `noindex`.
- [ ] No claims without a generated source; LIMITATIONS linked from the landing page.
- [ ] Lighthouse (mobile, production build) meets module 15 thresholds.
