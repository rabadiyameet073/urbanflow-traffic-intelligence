# Skill: hackathon-submission

**Use when:** Preparing submission materials; final week.

**Read first:** `platform-specifications/05`, `quality-and-audits/61`, Rule 15

## Rules

1. Map each rubric criterion to concrete evidence in the README.
2. Video ≤ 3 min; every number from `results.json`; show the Kernel rejecting an unsafe proposal and a TIGHT EVP case.
3. Record Muse prompts and honest failures; document Meta tools used.
4. Run the 20-point checklist; dry-run Judge Q&A.
5. Human submits ≥ 6 h early and creates `submission-v1`.
6. Verify portal fields and limits 🔎 (V5).

## Good / Bad

- ✅ README table: Criterion → Evidence → File/Test.
- ❌ Claims in the video that are not in `results.json`.

## Landmines

- Last-minute dependency or content changes break the freeze; do not.
