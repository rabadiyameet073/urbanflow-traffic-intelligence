# Skill: skill-maintenance

**Use when:** Updating this pack, rules or skills.

**Read first:** Rule 16, `AGENTS.md`

## Rules

1. Rules change only with human approval and an ADR; skills may be improved by agents with review.
2. Keep the Self-Containment Law: no pointers without content.
3. Update `README.md` index and run `node helpers/validate-pack.mjs` after any change.
4. Remove stale statements; mark provider facts 🔎 with dates.
5. Never leave residue from other projects in the pack.

## Good / Bad

- ✅ Add a Landmine learned this week.
- ❌ Adding a rule that duplicates another.

## Landmines

- Broken relative links are the most common pack defect.
