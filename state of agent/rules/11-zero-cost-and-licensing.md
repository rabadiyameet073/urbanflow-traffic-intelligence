# Rule 11 — Zero Cost and Licensing (inviolable)

The project runs on free tiers and hackathon credits, and every dependency, model and asset has a licence we can honour.

## Protocol

1. Target spend is **$0**. Anything that could incur cost needs a human decision, an ADR and a hard cap (module 57 §7).
2. Allowed platforms: Cloudflare free plan, GitHub public repo, Docker locally, Colab/Modal free tier or credits, Meta Model API within credits. No AWS/GCP/Azure paid services, no other vendor model APIs.
3. Free-tier limits are 🔎 **verified against current docs** before design depends on them; record the check date in `docs/ARCHITECTURE.md`.
4. Licences: MIT/BSD/Apache/ISC allowed; weak copyleft only with review; **GPL/AGPL not allowed in shipped code**. Project licence is MIT.
5. Model licences (SAM, Llama) and dataset terms are accepted **by the human**; agents record them and never click through.
6. Fonts are self-hosted OFL fonts with licence files; images are generated or licensed; no scraped photos.
7. `docs/CREDITS.md` lists every dependency, model, dataset, font and tool; generated by a script plus manual model/dataset entries.
8. No analytics/tracking SDKs (audit A13).

## Good / Bad

| ✅ | ❌ |
|---|---|
| Add `uPlot` (MIT, 45 KB) with an ADR line | Add a GPL charting lib |
| Caps + caching on Meta API calls | Unbounded calls "while testing" |

## Enforcement

`license-checker`/`pip-licenses` in CI, `audit.sh` A13–A14, review checklist, module 57 pin policy.
