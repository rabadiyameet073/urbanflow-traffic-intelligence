# Rule 12 — Contracts Are the Source of Truth (inviolable)

Names, types and constants are defined once (module 02, implemented in `packages/core/src/contracts.ts`) and derived everywhere else.

## Protocol

1. Frozen: lane IDs (NB-TR, NB-L, SB-TR, SB-L, EB-TR, EB-L, WB-TR, WB-L), phase IDs (P1_NS_LEFT, P2_NS_THRU, P3_EW_LEFT, P4_EW_THRU), timing constants, Kafka topic names, reason codes, error envelope.
2. One zod schema produces the TS type, runtime validation, JSON Schema and test data. No hand-written duplicate interfaces.
3. Spark `StructType`s are generated from, or parity-tested against, the schemas.
4. Constants have **one** definition; other packages import them. Magic numbers duplicating a contract value are defects.
5. **Changing a contract** follows module 02's procedure: ADR → human approval → schema version bump → migration/N−1 reader → update all consumers and docs in one change → golden fixtures regenerated.
6. Units appear in names (`laneLengthM`, `yellowS`, `speedMps`).
7. Wire payloads are versioned (`schemaVersion`); unknown versions are rejected with a clear code.
8. Generated artefacts (`docs/api/*.json`) are regenerated by script; CI fails on drift.

## Good / Bad

| ✅ | ❌ |
|---|---|
| `import { YELLOW_S } from '@urbanflow/core'` | `const yellow = 3.5` in the edge |
| `type LaneId = typeof LANES[number]` | Separate `LaneId` string union in web |

## Enforcement

Contract tests, schema drift check, dependency-cruiser rule (contracts imported, not copied), review checklist §2.3.
