# Copilot Evals (Module 24 §9)

30 simulator-generated, labelled incidents with three baselines (rule-based
heuristic · Llama fallback · Muse Spark), measured on the same metrics:
top-1/top-2 cause accuracy, severity agreement, % ADJUST_PARAMS proposals
passing the kernel bounds, p50/p95 latency and estimated cost.

## Lifecycle

| Step | Command | Needs key? | Output |
|---|---|---|---|
| 1. Build | `pnpm build` | no | dists the scripts import |
| 2. Dataset | `pnpm eval:gen` | no | `fixtures/incidents.json` (commit once) |
| 3. Record | `pnpm eval:live` | `META_API_KEY` | `fixtures/responses/muse-spark/*.json` (commit) |
| 4. Replay | `pnpm eval:replay` | no | `out/report.md` + floor gate (commit report) |
| 5. Floor | `pnpm eval:replay -- --record-floor` | no | records `floor.json` after a trusted run |

`eval:replay` is key-free and deterministic — provider answers come from the
recorded fixtures, the heuristic is recomputed live by the deterministic
template provider. CI may run it once fixtures are committed; it fails (exit 1)
when the primary source drops below the recorded top-1 floor.

## Honesty rules (Rule 00)

- `out/report.md` is **generated only** — never hand-type numbers into it or
  into `docs/validation/RESULTS.md`; copy from the generated file.
- Baselines without recorded fixtures are reported as omitted, not estimated.
- "% proposals with positive what-if Δ" is a benchmark (`packages/bench`)
  metric; the replay deliberately does not report it.
- `floor.json` ships with `top1PctFloor: null` until a real run records it.
- Where Muse Spark loses to the heuristic, the report says so; that is a
  credibility feature, not a defect to hide.

## Files

- `harness.mjs` — dist loaders, window builder, metric maths, class table.
- `generate.mjs` — drives `SimEngine` + `SafetyKernel` + `AdaptiveController`
  with per-class fault injection (the SIGNAL_FAULT frozen-indication trick is
  offline-only; no product path bypasses the kernel — see header).
- `replay.mjs` — baselines, metrics, report, regression gate.
- `live.mjs` — 5-incident paid smoke; records fixtures for replay.
- `fixtures/` — committed dataset + recorded provider responses.
- `out/` — generated report (safe to delete; regenerated by replay).
